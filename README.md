# Md. Ashifur Rahman — Portfolio

A responsive, modern personal portfolio website for **Md. Ashifur Rahman**, built with plain HTML, CSS and JavaScript.

## Run locally

Open `index.html` in a browser.

## Deploy to GitHub Pages

1. Create a GitHub repository (for example: `ashifur-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will publish the site.

## Notes

- No build step or framework is required.
- Replace/add GitHub and LinkedIn links in `index.html` if desired.
- The portfolio intentionally does not expose private family details or references from the CV.
